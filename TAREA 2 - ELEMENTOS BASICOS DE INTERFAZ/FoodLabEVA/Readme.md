# FoodLab - Android Views/XML

## Descripción

Esta carpeta contiene la implementación de **FoodLab** desarrollada de forma nativa para Android utilizando Kotlin y el sistema tradicional de Views y layouts XML.

El objetivo de esta versión es implementar las mismas funciones principales del catálogo FoodLab realizado en Flutter, utilizando componentes nativos de Android y separando la lógica escrita en Kotlin de la definición visual realizada mediante XML.

## Tecnología

- Android nativo
- Kotlin
- Views
- XML
- Material Design
- Android Studio
- Gradle

# Tarea 2 - Elementos básicos de interfaz de usuario

## Desarrollo de Aplicaciones Móviles Nativas

### FoodLab - Catálogo interactivo de interfaces móviles

FoodLab es una aplicación desarrollada como parte de la Tarea 2 de la materia Desarrollo de Aplicaciones Móviles Nativas.

El objetivo de la práctica es construir un catálogo interactivo de elementos de interfaz de usuario e implementar las mismas funciones utilizando diferentes tecnologías de desarrollo móvil. Esto permite identificar los componentes básicos de una interfaz, sus equivalencias entre plataformas y las diferencias entre los distintos enfoques de construcción.

## Tecnologías

La aplicación se desarrolla en tres tecnologías:

1. Android nativo con Views y XML.
2. Android nativo con Jetpack Compose.
3. Flutter con Dart.

Cada implementación mantiene la misma temática y organización general, adaptando los componentes a las herramientas propias de cada tecnología.

## Temática

La aplicación utiliza la temática **FoodLab**, un catálogo de recetas que permite explorar, preparar y organizar platillos mientras se muestran de manera interactiva diferentes componentes de interfaz móvil.

Las seis secciones principales son:

1. Crea tu receta
2. Acciones de cocina
3. Personaliza tu menú
4. Explora recetas
5. Cocina en progreso
6. Diseño de FoodLab

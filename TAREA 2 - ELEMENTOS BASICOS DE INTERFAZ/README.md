# FoodLab — Catálogo interactivo de interfaces móviles

**Asignatura:** Desarrollo de Aplicaciones Móviles Nativas

**Nombre:** Mayra Solís Lugo

**Grupo:** 7CV4

## Descripción

FoodLab es un catálogo interactivo de componentes de interfaz móvil
con temática de recetas y cocina.

La aplicación se implementa en tres tecnologías:

- Android nativo con Views y XML.
- Android nativo con Jetpack Compose.
- Flutter.

Cada versión contiene una pantalla principal y seis secciones de
componentes interactivos.
